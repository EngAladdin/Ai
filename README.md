# طبيب — نظام التنبؤ بالأمراض v2.0 🏥

## 🆕 ما الجديد في v2.0

- ✅ **خطة علاج كاملة** لكل مرض (أدوية + نمط حياة + متى تزور الطبيب)
- ✅ **وضع الليل (Dark Mode)** مع حفظ التفضيل
- ✅ **سجل التحليلات** محفوظ في المتصفح (localStorage) لا يمسح عند إغلاق التبويب
- ✅ **واجهة محسّنة** بتصميم عصري مع sidebar + grid layout
- ✅ **مودال تفصيلي** للعلاج عند الضغط على أي مرض
- ✅ **إصلاح منطق الـ fallback** لحساب دقيق للاحتمالية
- ✅ **أداء محسّن** بـ O(1) lookup للأعراض
- ✅ **لا pandas** - حذف الاعتمادية غير الضرورية

## 🚀 تشغيل المشروع

```bash
pip install -r requirements.txt
python app.py
```

افتح: http://localhost:5000

للوضع المطوّر:
```bash
FLASK_DEBUG=true python app.py
```
